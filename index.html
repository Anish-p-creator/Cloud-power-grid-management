AI-driven AWS cloud for smart EV fast-charging & power grid management

Ten 150–350 kW chargers ramping up at 6 PM can trip a feeder that was never built for that peak. GridSync bridges utility OpenADR and charger OCPP on serverless AWS, and makes every decision with three machine-learning models trained live in your browser: a neural-network demand forecaster, a reinforcement-learning charging agent and an Isolation Forest intrusion detector. New limits reach the chargers in under 2 seconds, before the protection relays trip.

    Model 3 · Unsupervised learning

    Telemetry guard: Isolation Forest IDS

    150 random isolation trees fitted on an unlabelled slice of the charger message stream. Physics-informed features: voltage deviation, the P − V·I residual, compliance with the commanded limit, message cadence and power level.

    The problem: four pillars

    There is usually enough power on the grid. What goes wrong is timing and coordination: dozens of chargers switch on independently, and none of them can see how much headroom the local transformer has left.

    01

    Protocol disconnect

    Utilities speak OpenADR and chargers speak OCPP. Nothing bridges them natively, so every site relies on one-off glue code.

    02

    Latency at scale

    Traditional backends queue up when 50 chargers report at once and take 15–30 s to respond. Protection relays trip much faster than that.

    03

    Static allocation

    Each charger's power ceiling is fixed at install time. It ignores the time of day, the grid state and each car's state of charge.

    04

    Vulnerable edge

    Chargers sit outdoors on public cellular links, often with password authentication. A compromised charger can become a way into grid signalling.

    Objectives

    • < 2 s system reaction time during grid stress
    • ≥ 35% reduction in utility peak demand charges
    • < 100% transformer load, zero tripping events
    • 99.99% cloud uptime (≈ 52 min/year downtime)
    • Zero-trust end-to-end hardware security

    Literature survey · 2020 → 2026

    The field moved from the cloud as an observer to the cloud as a decision-maker. None of the 10 papers combine protocol translation, sub-2 s control, dynamic allocation and zero-trust security, and that gap is what this project addresses.

    Security & cost

    🔐 Mutual TLS (X.509)

    The charger and IoT Core verify each other's certificates. There is no shared secret to leak, and any single device can be revoked on its own.

    🗝️ AWS KMS encryption

    Timestream, DynamoDB and S3 backups are encrypted at rest, and KMS rotates the keys automatically.

    🛡️ Private VPC

    Lambda, Step Functions and the databases are not exposed to the internet. Only API Gateway and IoT Core face outward.

    💸 Serverless pay-per-use

    Lambda, API Gateway, Step Functions, Kinesis and on-demand DynamoDB cost almost nothing when idle overnight.

    🧊 S3 tiering

    Telemetry older than 90 days moves from hot Timestream to S3 Infrequent Access or Glacier.

    📉 Fargate Savings Plans

    Predictable workloads such as scheduled SageMaker retraining run at a lower committed rate.

    What's novel

    The literature splits into cloud forecasting that cannot act in real time, edge AI that is hard to audit, and security treated as a separate topic. GridSync joins all three into one closed, explainable loop on serverless AWS.

    01Forecast-informed RL control

    A neural-network forecast feeds a reinforcement-learning agent that learns how much safety margin to keep. On 30 unseen days it cut overloads by about 99% against a fixed cloud rule, instead of relying on a hand-tuned limit.

    02Security that acts on the grid

    A physics-informed Isolation Forest scores every OCPP message. A flagged charger has its IoT Core certificate revoked automatically and its power is reallocated in the same control cycle, so the security and grid-control loops are joined.

    03Explainable decisions

    Every AI action comes with Q-values and forecast feature attributions in plain language. This addresses the auditability gap the 2026 edge-agent papers leave open.

    04OpenADR ⇄ OCPP in under 2 s, serverless

    Utility signals become charger limits in under 2 seconds. The design scales from one site to thousands of chargers with no servers to manage.
